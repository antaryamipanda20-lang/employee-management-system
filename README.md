# Employee Management System

Spring Boot + MySQL application with REST APIs for managing employee records.

## Features
- Add a new employee
- View all employees
- Update employee details
- Delete an employee

## Tech Stack
- Java
- Spring Boot
- MySQL
- REST APIs
- Maven

## How to Run
1. Clone the repo: `git clone https://github.com/antaryamipanda20-lang/employee-management-system.git`
2. Create a MySQL database and update the username and password in `application.properties`
3. Run the app with `mvn spring-boot:run`
4. Test the APIs in Postman at `http://localhost:8080`
